# Estado do núcleo local

O núcleo local foi implementado com dados fictícios. O projeto está pausado e publicado para instalação própria; não há serviço central, contas ou credenciais compartilhadas.

- [x] Ambiente Python 3.12 e dependências travadas.
- [x] SQLAlchemy, SQLite, PostgreSQL e migrações Alembic.
- [x] Áreas, categorias, projetos, tags, contas e operações financeiras auditadas.
- [x] Receitas, despesas, rateios, transferências, reembolsos, cartões e parcelas.
- [x] Limites, metas, contribuições, recorrências e agenda.
- [x] Inbox/outbox, confirmações duráveis, idempotência e recuperação.
- [x] Propostas estruturadas por IA e autorização no backend.
- [x] Telegram, transcrição, interpretação de imagens e staging CSV/XLSX.
- [x] Consultas, cenários, PNG, CSV e XLSX locais.
- [x] Health/webhook e templates de execução Docker/PaaS.
- [x] Backup cifrado e restauração isolada.
- [x] Testes determinísticos e jornada completa fictícia sem rede.
- [ ] Conectores Microsoft/Google e objetos nativos online.
- [ ] Painel completo instalado por padrão e virada mensal do workbook.
- [ ] Hospedagem contínua, medição de recursos e backup externo.
- [ ] Escolha/teste real de voz TTS, retenção e teto de consumo.
- [ ] Compartilhamento, exclusão definitiva e aceite do piloto.

Consulte [validação](validacao.md), [operação](operacao.md) e [retomada](retomada.md). Publicar o código não transforma uma função planejada em integração concluída.
